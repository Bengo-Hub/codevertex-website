# Image sources

Every photo on the site, where it came from and how it was prepared. Photos are cropped, resized
to at most 1800 px wide and saved as WebP (quality 72 to 78). Saving only the pixel data drops all
EXIF, including GPS. Crops remove number plates, burned-in timestamps and the old
"CodeVertex IT Solutions" logo.
